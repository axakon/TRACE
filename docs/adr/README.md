# Architecture Decision Records

Framework-level decisions for TRACE. Each ADR captures one decision: the context, what was chosen, and the consequences. Format follows the lightweight Michael Nygard template.

When to write an ADR: any structural choice, pattern recommendation, or deferred question resolved that affects how TRACE is built or how the playbook will read. Decisions only — raw observations and open questions stay in `docs/working-notes/`.
