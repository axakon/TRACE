# Reference layer

Long-form rationale for the playbook. Each file here is promoted from a stabilized working note in `docs/working-notes/` once its opinions stop moving. The original note remains as historical substrate (frozen, not deleted).

Reference docs are the **why**. Imperative how-to lives in `docs/playbook/`. Every playbook section links back to the reference doc(s) and ADR(s) it was synthesized from.

This folder is currently empty. Files appear as notes mature.
