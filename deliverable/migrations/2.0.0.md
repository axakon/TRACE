# Move to TRACE 2.0.0

TRACE 2.0.0 merged the plugins trace-plan, trace-git and trace-full into one plugin, trace. Remove every old TRACE install on this machine and install trace again. Use the claude plugin CLI through Bash.

1. Run `claude plugin list --json`. List every entry whose id ends in `@trace`, with its scope and projectPath. Show me the list and wait for my OK.
2. Uninstall each entry at its own scope, in this order: trace-full, trace-plan, trace-git, then trace. For project or local scope, run the command from inside that projectPath. If the projectPath no longer exists, create it, uninstall there, and then delete only the folder you created.
3. Run `claude plugin marketplace update trace`. If the trace marketplace is missing, run `claude plugin marketplace add axakon/TRACE`.
4. Run `claude plugin install trace@trace`. If step 2 removed TRACE from a `.claude/settings.json` that git tracks, also run `claude plugin install trace@trace --scope project` in that repository.
5. In the user settings file, set `"autoUpdate": true` on `extraKnownMarketplaces.trace`. Change nothing else in the file. The user settings file is `$CLAUDE_CONFIG_DIR/settings.json`, or `~/.claude/settings.json` when that variable is not set.
6. Run `claude plugin list --json` again and check that trace@trace is the only TRACE entry. Do not commit anything. List each changed `.claude/settings.json` with its repository and branch. Tell me to commit the change only on the default branch. Tell me that on other branches I can take the default branch's version of the file when I merge. Then tell me to restart Claude Code.
