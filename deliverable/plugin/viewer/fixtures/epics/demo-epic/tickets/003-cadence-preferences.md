# 003. Cadence preferences UI

## Why

One cadence doesn't fit everyone — high-touch projects want real-time, quiet ones want monthly.

## Scope

A settings section where a user picks per-project cadence (real-time / weekly / monthly), stored on the membership, respected by both the collector's routing and the digest scheduler.

## Out of scope

New digest layouts or per-event-type filtering.
